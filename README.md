# AgentsPod Landing Page

Single-page landing site for `agentspod.ai`, built with Next.js, React, TypeScript, and Tailwind CSS.

## Run locally

1. `npm install`
2. `npm run dev`
3. Open `http://localhost:3000`

## Quality checks

1. `npm run lint`
2. `npm run build`

## Production

Build the app with `npm run build`, then serve the production output with `npm start`.
